## 🌟 Elite Finish

A modern **Arabic interior design and finishing website** built with **Next.js** and **Tailwind CSS**.

---

## ✨ Features

- 🌙 **Modern and elegant Arabic design**
- 📱 **Fully responsive** across all devices
- 🎨 **Beautiful UI** with subtle animations
- 📧 **Integrated with EmailJS** for contact form submissions
- ⚡ **Fast and optimized** for performance
- 🔧 **Built with Next.js 14 & TypeScript**
- 🚫 **No CDN dependencies** – all assets are hosted locally

---

## 🧠 Tech Stack

- **Next.js 14** – React framework for modern web apps  
- **TypeScript** – Strongly typed, maintainable code  
- **Tailwind CSS 3.4** – Utility-first CSS framework  
- **Font Awesome** – Local icons  
- **Google Fonts** – Arabic fonts (Cairo, Tajawal)  
- **EmailJS** – Email integration for contact form  

---

## 🧩 Prerequisites

- **Node.js 18+**
- **npm** or **yarn**
